Оновлення надбудови «Відвідування» (v3)

1. У репозиторії attendance-addin на GitHub: Add file -> Upload files.
   Завантажте taskpane.html та index.html (однакові файли) і підтвердіть заміну (Commit changes).
   manifest.xml та іконки змінювати не треба.
2. Зачекайте 1-2 хвилини, закрийте панель у Excel і відкрийте знову (за потреби Ctrl+F5).

Що нового: вкладка «Тьютор» — зведення по ваших учнях з усіх вчительських аркушів,
практикумів і «Сьогодні у школі» (лише читання). Ім'я тьютора береться з аркуша
і змінюється в ⚙.
