Оновлення надбудови «Відвідування» (v4)

1. У репозиторії attendance-addin на GitHub: Add file -> Upload files.
   Завантажте taskpane.html та index.html (однакові файли) і підтвердіть заміну (Commit changes).
   manifest.xml та іконки змінювати не треба.
2. Зачекайте 1-2 хвилини, закрийте панель в Excel і відкрийте знову (за потреби Ctrl+F5).
3. При першому відкритті панель попросить обрати свій аркуш (один раз).
   Це потрібно й для вас: оберіть «Шелест Євгеній».

Що нового:
- Вкладка «Тьютор»: кнопка «+ Додати учня» (список під спостереженням, зберігається у вашому браузері).
  За замовчуванням пошук лише серед учнів ваших курсів; у ⚙ можна ввімкнути пошук по всій школі.
- Вибір свого аркуша при першому запуску: надбудову можна давати іншим вчителям (їм потрібен manifest.xml).
