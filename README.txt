Відвідування 2.0 — версія 6: дві окремі надбудови

1) «Відвідування» (для вчителів) — taskpane.html + index.html. Маніфест manifest.xml НЕ змінився, перепідключати не треба.
2) «Тьютор» (лише читання) — tutor.html + manifest-tutor.xml + іконки icon-t-16/32/64/80.png.

Що робити:
1. У GitHub-репозиторії attendance-addin завантажте (Add file → Upload files) і замініть: taskpane.html, index.html, tutor.html, icon-t-16.png, icon-t-32.png, icon-t-64.png, icon-t-80.png. Commit changes.
2. Зачекайте 1–2 хвилини. Закрийте й знову відкрийте панель «Відвідування» (за потреби Ctrl+F5).
3. Підключіть «Тьютор»: Вставлення → Надбудови → Передати мою надбудову → manifest-tutor.xml. З'явиться кнопка «Тьютор» на вкладці «Основне».
4. Колегам: вони підключають лише «Відвідування» через manifest.xml; на першому запуску обирають свій аркуш і позначають розклад.
